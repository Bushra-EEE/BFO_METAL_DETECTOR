# Documentation Images

The supplied ZIP contains these stage images:

| File | Stage |
|---|---|
| `01_colpitts_oscillator.png` | Colpitts oscillator stage |
| `02_gilbert_cell_mixer.png` | Gilbert-cell mixer stage |
| `03_active_lpf.png` | Active low-pass filter |
| `04_active_hpf.png` | Active high-pass filter |
| `05_power_amplifier.png` | Push-pull power amplifier |
| `06_complete_bfo_circuit.png` | Complete BFO circuit diagram/image |

The complete-circuit image is present in the ZIP even though the corresponding editable `complete_bfo_circuit.sch` source is not present.

## Reported Design Parameters

- Oscillator region: approximately 600 kHz
- LPF cutoff: **10 kHz**
- HPF cutoff: **736 Hz**
- Final beat tone: approximately **3.56 kHz**
- Power stage: **TIP31/TIP32 complementary push-pull**
